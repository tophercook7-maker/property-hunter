The service

Send an Arkansas address. Get back what the public record actually says about it, in one file.

Before you make an offer, bid at the State sale, or write to an owner, you want to know what is on record: taxes, the State's own tax-sale history, flood zone, road access, City liens, vacancy and code cases, the owner of record, and what nobody has checked yet. Property Hunter asks every public source through one guarded path and writes down what each one said, with the date. What a source could not answer stays unknown. Nothing is guessed.

What is in a file

IdentityThe parcel number, county, RPID, situs, coordinates and acreage, verified on the State roll, with the record date and the date it was read. An address that could mean two parcels is never silently picked.
Taxes and the State saleThe county Collector's answer as of a date, or the honest fact that the Collector did not answer. The State Lands inventory, certification, sale and redemption history. A current bill is never called a delinquency; absence from the State list is never called "taxes current".
Land and recordsFEMA flood zone at the parcel. Nearest mapped road, kept separate from legal access. Assessor values, legal description and class from the roll. In Hot Springs: the City's vacancy register, cleanup and demolition liens, and code cases, each as a dated answer.
What is unknown, and what to doEvery open question is listed by name: title, deed, mailing address, listing, physical condition. Each one has a next step: what to check, why, where, and what would answer it. Nothing is hidden behind "nothing found".
What failedA source that was down, blocked, or manual-only is shown as exactly that, with the reason. You will always know what the system actually checked.
The record trailEvery fact carries its source, record date, read date and evidence reference. Two sources that disagree are shown side by side, never merged.

How it works

  1. You send an address, or a parcel number with its county (lots without a house number are common at the State sale).
  2. The address is resolved to one parcel on the live State roll by written rules. If it could be more than one, you get the list and choose.
  3. Every applicable source is asked once, through one guarded path, and every answer or failure is recorded.
  4. You get the file, the same layout as the samples, with the open questions and next steps at the end.
  5. Manual follow-up is optional. Deed at the Circuit Clerk, the owner's mailing address, a listing check, an exterior look. Each closes a named gap and is recorded as a dated human verification, never as a guess.

What a file will not do

It will not tell you a property is a good deal, or what it is worth. Assessor values are the assessor's figures, not a price.
It will not say title is clear. Only a title search does that, and the file says so.
It will not say an owner wants to sell, or that a house is vacant or distressed, unless a public register or a person on the sidewalk recorded it.
It will not read sites that refuse automated access. Those are named as manual steps, with the office to visit.
It will not contact anyone. Outreach, if you want it, is prepared for you to review and send yourself.

How to ask for one

Email the address or parcel number and the county. You get back a quote for the file and, if you want the manual follow-up, a quote for that as a separate line. Reply to accept and the file comes back to the same email.
