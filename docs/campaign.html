Letter preparation has moved into investigation cases. The old Letters page built a letter from scan flags alone: a flag on a register, a lien on a map, an absentee mailing address. A flag is not evidence enough to write to someone. A draft is now prepared only from an investigation whose evidence gate is open, it says only what the evidence supports, and the site never sends anything. You review it, you print or mail it yourself, and you record what you did.
